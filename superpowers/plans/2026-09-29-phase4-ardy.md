**Goal:** Generate ARDY Core motion from Houdini: an ARDY model server on the shared fxmotion contract, and a `vb::ardy_motion::1.0` node with the same timeline, root path and pose keys as `kimodo_motion` 2.0.

## Decisions taken while planning

1. ARDY v1 has no Regenerate (`continue` capability off): ARDY continues from normalised motion features, not Kimodo's local rotations, and nobody asked for partial re-rolls of ARDY clips yet. The ARDY asset has no Regenerate buttons.
2. Timeline segments are chained with `init_history_sequence` (measured in planning: seam step 0.008 m against a 0.027 m clip median, the second prompt followed). ARDY refuses `crop_history_length` with a history, so the history is the whole clip so far: ARDY's own code says unbounded history degrades past its trained 10 s window. The server logs a warning past 10 s; Review Focus 1 measures it.
3. `ardy_core` rest rotations are the identity. ARDY ships no `standard_t_pose_global_offsets_rots.p` for Core, so its identity rotation is the joints.p T-pose with world-aligned frames. Checked in planning: the skin's `bind_rig_transform` rotations applied to joints.p's bone offsets reproduce its bind translations exactly (the bind is an A-pose over that T-pose), except the two thumbs, whose skin bone is 4.6 cm against joints.p's 5.7 cm (about 1 cm of thumb stretch under Joint Deform, accepted). The cost: joint frames are world-aligned, not bone-aligned like SOMA77's; phase 2 (retarget) may want bone-aligned offsets and can add them to the registry then.
4. Time bounds (phase 1 fix) are loosened: a key or waypoint time up to the requested duration is clamped to the last generated sample; only times beyond the requested duration are refused. At 20 fps each segment truncates up to one sample, so a key on the last scene frame can land several samples past the generated clip.
5. The ARDY node's icon is `NVIDIA_badge.svg` (no ARDY logo exists).

## Review Focus

1. A timeline longer than ARDY's 10 s window: the motion keeps its quality or the user is told. Pinned in Task 3 (`tests/ardy_integration.py`, the 12 s three-segment case, and the server's warning).
2. The Kimodo text-encoder container is not running: ARDY's server says so by name, not with a gradio traceback. Pinned in Task 3 (`test_text_encoder_down_is_named`).
3. A pose key or waypoint on the last frame of a timeline at 24 or 25 fps: accepted. Pinned in Task 2 (`test_last_frame_key_at_20_fps_is_accepted`).

Move the body of `server/kimodo_adapter.py` into `server/diffusion_adapter.py` and parametrise it. The complete module:

```python
"""Motion-diffusion model output <-> fxmotion clips, for any model that
speaks Kimodo's NPZ and constraint conventions (Kimodo, ARDY).

Pure numpy, no torch. A ModelSpec says which skeleton and frame rate a model
uses; everything else is shared. Two spaces meet here:
  model space  where the model generates: root at XZ (0, 0) facing +Z on the
               first sample; rotations column-vector, world-axis-aligned at
               rest.
  Houdini      where the request and the clip live: the root path as drawn;
               rotations row-vector and bone-aligned, ready for KineFX.
Canon moves positions and rotations between the two frames.
"""

from __future__ import annotations

import math
from dataclasses import dataclass

import numpy as np

from fxmotion import clipformat, skeletons

# Every per-sample array in a Kimodo or ARDY NPZ, kept as native_*.
NATIVE_KEYS = (
    "local_rot_mats",
    "global_rot_mats",
    "posed_joints",
    "root_positions",
    "smooth_root_pos",
    "foot_contacts",
    "global_root_heading",
)

# Joints behind each foot_contacts channel. A SOMA77 NPZ carries 6 channels
# (ToeEnd duplicates ToeBase); 4-channel NPZs (ARDY Core, Kimodo's internal
# representation) carry the detected pair per side.
FOOT_CHANNELS = {
    6: (
        "LeftFoot",
        "LeftToeBase",
        "LeftToeEnd",
        "RightFoot",
        "RightToeBase",
        "RightToeEnd",
    ),
    4: ("LeftFoot", "LeftToeBase", "RightFoot", "RightToeBase"),
}


@dataclass(frozen=True)
class ModelSpec:
    name: str  # prefixes every error: "kimodo: ...", "ardy: ..."
    skeleton: str  # an fxmotion.skeletons name
    fps: float


class AdapterError(ValueError):
    """A request the model cannot run; the server answers 422 with it."""


def yaw(ang: float) -> np.ndarray:
    """Rotation about +Y by `ang`, column-vector (the 1.1 cook's matrix)."""
    c, s = math.cos(ang), math.sin(ang)
    return np.array([[c, 0.0, s], [0.0, 1.0, 0.0], [-s, 0.0, c]])


@dataclass(frozen=True)
class Canon:
    """Where model space sits in Houdini: origin (ox, 0, oz), heading ang."""

    ox: float = 0.0
    oz: float = 0.0
    ang: float = 0.0

    @classmethod
    def from_xz(cls, xz) -> Canon:
        """Origin on the first point, heading toward the first point that
        is not on top of it (+Z if there is none)."""
        ox, oz = (float(v) for v in xz[0])
        dx, dz = next(
            (
                (x - ox, z - oz)
                for x, z in xz[1:]
                if abs(x - ox) + abs(z - oz) > 1e-4
            ),
            (0.0, 1.0),
        )
        return cls(ox, oz, math.atan2(dx, dz))

    def _origin(self) -> np.ndarray:
        return np.array([self.ox, 0.0, self.oz])

    def pos_to_model(self, p) -> np.ndarray:
        p = np.asarray(p, dtype=np.float64)
        return (p - self._origin()) @ yaw(self.ang)

    def pos_to_world(self, p) -> np.ndarray:
        p = np.asarray(p, dtype=np.float64)
        return p @ yaw(self.ang).T + self._origin()

    def rot_to_model(self, r) -> np.ndarray:
        return yaw(self.ang).T @ np.asarray(r, dtype=np.float64)

    def rot_to_world(self, r) -> np.ndarray:
        return yaw(self.ang) @ np.asarray(r, dtype=np.float64)

    def as_list(self) -> list:
        return [self.ox, self.oz, self.ang]


def sample(time_s, spec: ModelSpec) -> int:
    """Clip sample for a time in seconds."""
    return int(round(float(time_s) * spec.fps))


def _tpose(spec: ModelSpec) -> np.ndarray:
    """Column-vector offsets that make each joint frame bone-aligned (the
    transpose of the registry's row-vector rest rotations)."""
    rest = skeletons.get(spec.skeleton).rest_rot
    return np.swapaxes(rest.astype(np.float64), -1, -2)


def to_clip(npz, canon: Canon, spec: ModelSpec, *, segments=None, source=None) -> dict:
    """A model's NPZ output (model space) as an fxmotion clip (Houdini)."""
    skel = skeletons.get(spec.skeleton)
    pos = canon.pos_to_world(npz["posed_joints"])
    grot = canon.rot_to_world(npz["global_rot_mats"])
    # right-multiplying the offsets makes each frame bone-aligned, matching
    # the T-Pose output; the transpose is KineFX's row-vector form
    world_rot = np.swapaxes(grot @ _tpose(spec), -1, -2)
    contacts = None
    fc = npz.get("foot_contacts")
    if fc is not None and fc.shape[-1] in FOOT_CHANNELS:
        contacts = np.zeros(pos.shape[:2], dtype=np.int8)
        for ch, name in enumerate(FOOT_CHANNELS[fc.shape[-1]]):
            contacts[:, skel.index(name)] = fc[:, ch]
    return clipformat.make(
        spec.skeleton,
        skel.joint_names,
        skel.parents,
        spec.fps,
        pos,
        world_rot,
        skel.rest_pos,
        skel.rest_rot,
        contacts=contacts,
        segments=segments,
        source=dict(source or {}, backend=spec.name, canon=canon.as_list()),
        native={k: npz[k] for k in NATIVE_KEYS if k in npz},
    )


def _check_sample(what, time_s, spec, frames, duration_s) -> int:
    """The sample for `time_s` in a clip of `frames` samples. Segments
    truncate to whole samples while times round, so a time inside the
    requested duration can land a few samples past the generated clip:
    those clamp to the last sample. Negative times and times past the
    requested duration are refused. None for either bound: not checked."""
    t = float(time_s)
    if t < 0 or (duration_s is not None and t > duration_s + 1e-9):
        end = "" if duration_s is None else " to %g s" % duration_s
        raise AdapterError(
            "%s: %s time %g s is outside the clip (0%s)" % (spec.name, what, t, end)
        )
    f = sample(t, spec)
    return f if frames is None else min(f, frames - 1)


def keyframe_constraints(keyframes, canon: Canon, spec: ModelSpec, frames=None, duration_s=None) -> list:
    """Request keyframes (Houdini space, KineFX rotations) as model
    fullbody-global / ee-global dicts in model space. Keys sharing the same
    `joints` become one constraint."""
    skel = skeletons.get(spec.skeleton)
    count = len(skel.joint_names)
    tp_t = np.swapaxes(_tpose(spec), -1, -2)
    hips = skel.index("Hips")
    groups: dict = {}
    for kf in keyframes:
        pos = np.asarray(kf["world_pos"], dtype=np.float64)
        rot = np.asarray(kf["world_rot"], dtype=np.float64)
        if pos.shape != (count, 3) or rot.shape != (count, 3, 3):
            raise AdapterError(
                "%s: a keyframe needs world_pos (%d, 3) and world_rot "
                "(%d, 3, 3) for every %s joint, got %s and %s"
                % (spec.name, count, count, spec.skeleton.upper(), pos.shape, rot.shape)
            )
        joints = tuple(kf.get("joints") or ())
        unknown = [j for j in joints if j not in skel.joint_names]
        if unknown:
            raise AdapterError(
                "%s: unknown joints %s" % (spec.name, ", ".join(unknown))
            )
        # KineFX transform R = (grot @ tp).T, so grot = R.T @ tp.T
        grot = np.swapaxes(rot, -1, -2) @ tp_t
        groups.setdefault(joints, []).append(
            (
                _check_sample("keyframe", kf["time_s"], spec, frames, duration_s),
                canon.pos_to_model(pos),
                canon.rot_to_model(grot),
            )
        )
    out = []
    for joints, keys in groups.items():
        keys.sort(key=lambda k: k[0])
        c = {
            "frame_indices": [f for f, _, _ in keys],
            "global_joints_positions": [p.tolist() for _, p, _ in keys],
            "global_joints_rots": [r.tolist() for _, _, r in keys],
            "smooth_root_2d": [
                [float(p[hips, 0]), float(p[hips, 2])] for _, p, _ in keys
            ],
        }
        if joints:
            c.update(type="ee-global", joint_names=list(joints))
        else:
            c["type"] = "fullbody-global"
        out.append(c)
    return out


def _path_items(points, spec, frames, duration_s):
    """[(sample, [x, z])], deduplicated by sample (first wins), sorted."""
    timed = [p.get("time_s") is not None for p in points]
    if any(timed) and not all(timed):
        raise AdapterError(
            "%s: root_path points must all have time_s or none" % spec.name
        )
    xz = [[float(p["pos"][0]), float(p["pos"][2])] for p in points]
    if all(timed):
        at = [
            _check_sample("root_path", p["time_s"], spec, frames, duration_s)
            for p in points
        ]
    elif len(xz) > 1:
        # spread evenly over the samples the clip actually has
        last = max(1, frames) - 1
        at = [int(round(i * last / (len(xz) - 1))) for i in range(len(xz))]
    else:
        at = [0]
    by_frame: dict = {}
    for f, c in zip(at, xz, strict=True):
        by_frame.setdefault(f, c)
    return sorted(by_frame.items())


@dataclass
class ModelInputs:
    texts: list
    durations_s: list
    num_frames: list
    constraints: list
    canon: Canon
    transition_frames: int
    continue_from: dict | None


def model_inputs(req: dict, spec: ModelSpec) -> ModelInputs:
    """A GenerateRequest (as a dict) turned into what the model call takes.
    Raises AdapterError for anything it cannot run."""
    texts, durs = [], []
    for i, seg in enumerate(req.get("segments") or [], start=1):
        text = (seg.get("prompt") or "").strip()
        dur = float(seg.get("duration_s") or 0.0)
        if not text:
            raise AdapterError("%s: segment %d has no prompt" % (spec.name, i))
        if dur <= 0:
            raise AdapterError(
                "%s: segment %d needs duration_s > 0" % (spec.name, i)
            )
        texts.append(text)
        durs.append(dur)
    if not texts:
        raise AdapterError("%s: at least one segment is required" % spec.name)
    opts = req.get("options") or {}
    num_frames = [max(1, int(d * spec.fps)) for d in durs]
    total, duration = sum(num_frames), sum(durs)
    root_path = req.get("root_path") or []
    items = _path_items(root_path, spec, total, duration) if root_path else []
    if opts.get("canon") is not None:
        canon = Canon(*(float(v) for v in opts["canon"]))
    elif items:
        canon = Canon.from_xz([c for _, c in items])
    else:
        canon = Canon()
    native = opts.get("native_constraints") or []
    if not isinstance(native, list):
        raise AdapterError("%s: native_constraints must be a list" % spec.name)
    constraints = list(native)
    if items:
        constraints.append(
            {
                "type": "root2d",
                "frame_indices": [f for f, _ in items],
                "smooth_root_2d": [
                    canon.pos_to_model([x, 0.0, z])[[0, 2]].tolist()
                    for _, (x, z) in items
                ],
            }
        )
    constraints += keyframe_constraints(
        req.get("keyframes") or [], canon, spec, total, duration
    )
    cont = None
    cf = req.get("continue_from")
    if cf:
        try:
            cont = {
                "local_rot_mats": cf["native_local_rot_mats"],
                "root_positions": cf["native_root_positions"],
            }
        except KeyError as e:
            raise AdapterError(
                "%s: continue_from needs native_local_rot_mats and "
                "native_root_positions (%s missing)" % (spec.name, e)
            ) from e
    return ModelInputs(
        texts=texts,
        durations_s=durs,
        num_frames=num_frames,
        constraints=constraints,
        canon=canon,
        transition_frames=max(1, int(opts.get("transition_frames", 5))),
        continue_from=cont,
    )


def segment_ranges(inp: ModelInputs) -> list:
    """The clip's segments metadata: prompt and first/last sample."""
    out, start = [], 0
    for text, n in zip(inp.texts, inp.num_frames, strict=True):
        out.append({"prompt": text, "start": start, "end": start + n - 1})
        start += n
    return out
```

```python
"""The ARDY model server: ARDY Core on the shared fxmotion server.

Runs natively in ARDY's own venv (scripts/run_ardy_server.ps1). The text
encoder is the Kimodo text-encoder container's (same LLM2Vec model and API,
TEXT_ENCODER_MODE=api), so the two models share one copy. Every torch and
ardy import is inside a method: the module imports, and the MOCK_MODE server
runs, without them.

Timeline segments are chained: each segment is generated from the motion so
far as init_history_sequence (ARDY refuses crop_history_length together with
a history, so the history is the whole clip).
"""

from __future__ import annotations

import logging
import os
import tempfile
from pathlib import Path

import diffusion_adapter as da
import fxmotion_server as fs
import numpy as np
import requests

log = logging.getLogger("ardy_backend")
logging.basicConfig(level=logging.INFO)

ARDY = da.ModelSpec(name="ardy", skeleton="ardy_core", fps=20.0)
MODELS = ("ARDY-Core-RP-20FPS-Horizon40", "ARDY-Core-RP-20FPS-Horizon8")
# ARDY's trained context; past it, ARDY's own code warns the motion degrades
WINDOW_S = 10.0


def check_text_encoder(url: str, timeout: float = 3.0) -> None:
    """Raise a RuntimeError naming the URL when the text-encoder service
    (the Kimodo text-encoder container) does not answer."""
    try:
        requests.get(url.rstrip("/") + "/config", timeout=timeout).raise_for_status()
    except requests.RequestException as e:
        raise RuntimeError(
            "ardy: text encoder unreachable at %s; start the Kimodo "
            "text-encoder container (docker compose -f "
            "docker-compose.bridge.yaml up text-encoder -d): %s" % (url, e)
        ) from e


def _constraint_objects(dicts, skeleton) -> list:
    """Model-space constraint dicts (the shared adapter's output) as ARDY
    constraint sets. root2d and ARDY's own dicts go through
    load_constraints_lst; the global types through the constructors, as
    Kimodo's backend does."""
    import torch
    from ardy.constraints import (
        EndEffectorConstraintSet,
        FullBodyConstraintSet,
        load_constraints_lst,
    )

    device = skeleton.device
    std, out = [], []
    for c in dicts:
        kind = c.get("type")
        if kind in ("fullbody-global", "ee-global"):
            fi = torch.tensor(c["frame_indices"])
            pos = torch.tensor(c["global_joints_positions"], dtype=torch.float32, device=device)
            rot = torch.tensor(c["global_joints_rots"], dtype=torch.float32, device=device)
            root = c.get("smooth_root_2d")
            root = torch.tensor(root, dtype=torch.float32, device=device) if root else None
            if kind == "fullbody-global":
                out.append(FullBodyConstraintSet(skeleton, fi, pos, rot, root_2d=root))
            else:
                out.append(
                    EndEffectorConstraintSet(
                        skeleton, fi, pos, rot, root, joint_names=c["joint_names"]
                    )
                )
        else:
            std.append(c)
    return (load_constraints_lst(std, skeleton) if std else []) + out


class ArdyBackend(fs.Backend):
    name = "ardy"
    skeleton = "ardy_core"
    fps = ARDY.fps
    models = MODELS
    capabilities = {
        "text": True,
        "styles": [],
        "root_path": True,
        "keyframes": True,
        "effectors": True,
        "continue": False,
        "live": False,
    }

    def __init__(self, default_model="", mock_clip=None, text_encoder_url="http://127.0.0.1:9550/"):
        self.default_model = default_model or MODELS[0]
        self.mock_clip = Path(mock_clip) if mock_clip else None
        self.text_encoder_url = text_encoder_url
        self._model = None
        self._device = None

    def validate(self, req) -> None:
        da.model_inputs(req.model_dump(), ARDY)  # AdapterError is a ValueError

    def load(self, model: str) -> None:
        import torch
        from ardy.model.load_model import load_model
        from ardy.model.registry import resolve_model_name

        check_text_encoder(self.text_encoder_url)
        os.environ.setdefault("TEXT_ENCODER_MODE", "api")
        os.environ.setdefault("TEXT_ENCODER_URL", self.text_encoder_url)
        self._device = "cuda:0" if torch.cuda.is_available() else "cpu"
        name = resolve_model_name(model or self.default_model)
        log.info("[RESIDENT] loading %s on %s ...", name, self._device)
        self._model = load_model(name, device=self._device)
        log.info("[RESIDENT] model ready: %s", name)

    def unload(self) -> None:
        self._model = None
        import torch

        if torch.cuda.is_available():
            torch.cuda.empty_cache()

    def generate(self, req, progress) -> dict:
        import torch
        from ardy.motion_rep.tools import length_to_mask
        from ardy.postprocess import post_process_motion
        from ardy.tools import seed_everything, to_numpy

        inp = da.model_inputs(req.model_dump(), ARDY)
        model, device = self._model, self._device
        if req.seed is not None:
            seed_everything(int(req.seed))
        total = sum(inp.num_frames)
        if total / ARDY.fps > WINDOW_S:
            log.warning(
                "[ARDY] %.1f s clip is past ARDY's %.0f s window; the history is "
                "not cropped, so late segments may jitter",
                total / ARDY.fps,
                WINDOW_S,
            )
        constraints = _constraint_objects(inp.constraints, model.skeleton)
        observed = mask = None
        if constraints:
            observed, mask = model.motion_rep.create_conditions_from_constraints_batched(
                constraints,
                torch.tensor([total], device=device),
                to_normalize=True,
                device=device,
            )
        steps = int(model.diffusion.num_base_steps)
        motion, done = None, 0
        for k, (text, n) in enumerate(zip(inp.texts, inp.num_frames, strict=True)):
            progress.set(k / len(inp.texts), "segment %d/%d" % (k + 1, len(inp.texts)))
            done += n
            with torch.no_grad():
                motion = model(
                    [text],
                    done,
                    num_denoising_steps=steps,
                    pad_mask=length_to_mask(torch.tensor([done], device=device)),
                    first_heading_angle=None if motion is not None else torch.zeros(1, device=device),
                    motion_mask=None if mask is None else mask[:, :done],
                    observed_motion=None if observed is None else observed[:, :done],
                    init_history_sequence=motion,
                )
        progress.set(0.95, "post-processing")
        with torch.no_grad():
            out = model.motion_rep.inverse(motion, is_normalized=True)
            out.update(
                post_process_motion(
                    out["local_rot_mats"],
                    out["root_positions"],
                    out["foot_contacts"],
                    model.skeleton,
                    constraint_lst=constraints or None,
                )
            )
        out = to_numpy(out)
        single = {
            k: (v[0] if hasattr(v, "shape") and v.ndim > 0 and v.shape[0] == 1 else v)
            for k, v in out.items()
        }
        return da.to_clip(
            single,
            inp.canon,
            ARDY,
            segments=da.segment_ranges(inp),
            source={"model": req.model or self.default_model, "seed": req.seed},
        )

    def mock(self, req) -> dict:
        inp = da.model_inputs(req.model_dump(), ARDY)
        if self.mock_clip is None or not self.mock_clip.exists():
            raise FileNotFoundError(
                "MOCK_MODE serves an ARDY NPZ, none found at %s" % self.mock_clip
            )
        with np.load(self.mock_clip) as z:
            npz = {k: z[k] for k in z.files}
        return da.to_clip(
            npz,
            inp.canon,
            ARDY,
            segments=da.segment_ranges(inp),
            source={"model": "mock", "seed": req.seed},
        )


def make_app():
    default_out = Path(tempfile.gettempdir()) / "fxmotion" / "ardy"
    out = Path(os.environ.get("OUTPUT_DIR", str(default_out)))
    backend = ArdyBackend(
        default_model=os.environ.get("ARDY_MODEL", ""),
        mock_clip=os.environ.get("FXMOTION_MOCK_CLIP") or None,
        text_encoder_url=os.environ.get("TEXT_ENCODER_URL", "http://127.0.0.1:9550/"),
    )
    return fs.create_app(
        backend,
        output_dir=out,
        mock=os.environ.get("MOCK_MODE", "0") == "1",
        idle_unload_s=float(os.environ.get("FXMOTION_IDLE_UNLOAD_S", "0")),
```
